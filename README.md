# Universe 🌐 - Dashboard
Universe is a crowd visualization system that uses RTSP compatible IP cameras in conjuction with YOLOv8 computer vision to count people.
![universe](https://github.com/user-attachments/assets/7bcb556d-3591-448f-827e-4b5d3febe07b)
This is the frontend, it retrieves snapshots analyzed by universe-galaxy from a MongoDB server.
## Technologies used 💻
- Next.js
- Three.js
- MongoDB
- RabbitMQ
- OpenCV
- YOLOv8
